# AI Workflow

A version-controlled collection of personal working preferences and coding
conventions for AI-assisted software development.

## Files

- `personal-rules.md`: General instructions for how AI tools should work with me.
- `coding-patterns.md`: Coding conventions and technical patterns to follow.

## Usage

These files are the source of truth for my workflow preferences.

For Codex, the instructions are made available through `~/.codex/AGENTS.md`.
When the source files change, update the global instructions deliberately and
verify that the relevant instructions remain consistent.

Project-specific `AGENTS.md` files may add requirements for individual projects.

## Principles

- Keep implementations simple and maintainable.
- Avoid unnecessary dependencies and unrelated changes.
- Explain unfamiliar concepts when needed.
- Verify changes and clearly report what was tested.
- Improve this workflow based on actual experience rather than adding complexity
  without a demonstrated need.
